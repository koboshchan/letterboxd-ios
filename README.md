
## Sign-in status
Implemented but NOT verified end to end. Sign-in is the site's own page in a non-persistent WKWebView (the app does not read or store the password and never fakes the CSRF value or Turnstile token). "Done" collects cookies, keeps only those that apply to https://letterboxd.com, and saves them to the Keychain only after the server confirms the account on the homepage (`person.username` / `person.loggedIn` assignments, recorded fixture). Requests use only an in-memory, server-validated session; at launch the stored session is re-validated before any cookie is sent, so offline means no credentials. Authenticated requests never follow redirects, and caches are partitioned by an auth generation that changes on sign-in, sign-out and restore. Nobody has completed a real signed-in run in this app yet. Watchlist and list writes are unsupported.
